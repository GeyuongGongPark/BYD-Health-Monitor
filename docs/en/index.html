App Components

Three components, one system

Vehicle, server, and smartphone work together seamlessly.

🚗

Vehicle App

Installed on BYD DiLink headunit

Directly integrated with the BYD HAL OpenAPI to read real-time sensor data. Displays fault codes, tire pressure, and maintenance status on the in-car display. On CRITICAL fault detection, sends an alert to the relay server.

Kotlin Jetpack Compose Hilt · Room
☁️

Relay Server

Deployed on Railway

Receives fault alerts from the vehicle app, persists them in PostgreSQL, and immediately forwards push notifications to all registered smartphones. Handles FCM/APNs delivery since DiLink has no GMS.

Node.js PostgreSQL Firebase Admin
📱

Companion App

iOS & Android smartphones

Install on your personal smartphone to receive instant push notifications when a CRITICAL fault is detected, and browse the full alert history at any time. iOS uses APNs; Android uses FCM.

Flutter iOS APNs Android FCM
How It Works

Fault detected. Phone notified.

A real-time alert pipeline from vehicle to server to smartphone.

🚗
BYD DiLink Vehicle App
android/ · Kotlin + Jetpack Compose
  • Reads sensor data in real-time via BYD HAL OpenAPI
  • Analyzes 23 fault codes and classifies severity
  • On CRITICAL fault: sends to server with 1-hr cooldown & 3 retries
  • Displays fault, tire, and maintenance status on in-car screen
↓ HTTP POST /alert
☁️
Railway Relay Server
server/ · Node.js + PostgreSQL
  • Persists alert history in PostgreSQL
  • Sends APNs push to all registered iOS devices
  • Sends FCM push to all registered Android devices (500-batch)
  • Auto-cleans expired tokens weekly
↓ APNs / FCM
🍎
iOS Companion
iPhone · APNs
  • Instant push, even in background
  • Browse alert history
🤖
Android Companion
Smartphone · FCM
  • Instant push on GMS devices
  • Browse alert history
Features

Everything you need

Directly integrated with the BYD HAL OpenAPI for real-time vehicle data.

⚠️

Fault Code Translation

Translates 23 fault codes into human-readable descriptions with recommended actions. Categorized by CRITICAL · WARNING · INFO severity.

🔵

Tire Dashboard

Live pressure (kPa), temperature, air leak detection, and TPMS system status for all 4 tires — overlaid on a top-down vehicle graphic.

🔧

Maintenance Tracker

Track replacement intervals for engine oil, brake fluid, coolant, tires, AC filter, and brake pads. Log service history with mileage and notes.

📊

Health Score Gauge

A single 0–100 score summarizing fault severity and maintenance status, displayed with an animated circular gauge.

🔔

CRITICAL Alerts

Automatic status bar notification when a critical fault is detected. Built-in deduplication prevents repeated alerts for the same code.

📈

Battery & Range

Real-time battery percentage and estimated electric driving range displayed directly on the dashboard.

🌙

Dark Theme

Designed for in-vehicle use. A BYD-inspired dark color palette minimizes glare during night driving.

🔌

Mock Mode

Full UI works without a real vehicle. Automatically falls back to mock data when BYD OpenAPI is unavailable.

Build & Install via Android Studio

Connect your BYD DiLink via USB or wireless ADB to install directly.

1

Clone the repository

git clone https://github.com/GeyuongGongPark/BYD-Health-Monitor.git cd BYD-Health-Monitor
2

Open in Android Studio

Go to File → Open and select the cloned folder. Gradle sync starts automatically.

3

(Optional) Connect BYD OpenAPI

Extract bydauto-openapi.jar from a real DiLink unit via ADB and place it in android/libs/. Skip this step to run in Mock mode.

4

Deploy to DiLink

Connect your vehicle via USB, then hit Run in Android Studio or run:

./gradlew :android:installDebug
ℹ️

The app runs fully in Mock mode without a real BYD vehicle. Test the entire UI on any Android device or emulator before deploying to DiLink.
