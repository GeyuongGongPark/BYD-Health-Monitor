Privacy Policy

Last updated: September 17, 2026

1. Overview

BYD Health Monitor (the "App") is an open-source vehicle health monitoring app that runs on the BYD DiLink in-car display.

This App does not collect any personally identifiable information. All data remains on the vehicle device and is never transmitted to external servers.

2. Data We Process

The following table describes the data the App handles and where it is stored.

Data Type Description Storage
Fault Codes Real-time status of 23 fault codes via BYD HAL API. In-memory only
Tire Status Pressure (kPa), temperature state, and air leak detection for all 4 tires. In-memory only
Battery & Range Battery percentage, estimated electric driving range, total mileage. In-memory only
Maintenance History Replacement records entered manually by the user: date, mileage, and optional notes. Local device DB

Vehicle data is queried in real time during app use and discarded when the session ends. Only user-entered maintenance history is persisted to an on-device Room database.

3. Data We Do Not Collect

  • Personal identifiers such as name, email address, or phone number
  • Location data (GPS or network-based)
  • Usage logs or analytics events
  • Advertising identifiers (ADID, IDFA, etc.)
  • Camera or microphone data
  • Contacts, calendar, photos, or other personal device data

4. Data Storage & Security

Maintenance history is stored exclusively in an SQLite database (Room) on the DiLink device itself. It is never synced to external servers or cloud storage.

  • Uninstalling the App permanently deletes all locally stored data.
  • No third-party SDKs, ad networks, or analytics tools are included.
  • The App functions fully without an internet connection.

5. App Permissions

Permission Purpose
POST_NOTIFICATIONS Displays a status bar notification when a CRITICAL fault code is detected. You can disable this at any time in system settings.
INTERNET Reserved for Phase 7 (smartphone integration). Not used in the current version.
FOREGROUND_SERVICE For background vehicle monitoring via a foreground service (planned).

6. Third-Party Sharing

We do not sell, share, or transmit any data to third parties.

The App uses the following open-source libraries. None of them collect or transmit user data.

  • Jetpack Compose, Hilt, Room — Google Android Jetpack (Apache 2.0)
  • Kotlin Coroutines — JetBrains (Apache 2.0)

7. Children's Privacy

This App is intended for vehicle operators. We do not knowingly collect any data from children under the age of 13.

8. Changes to This Policy

This Privacy Policy may be updated as the App evolves — particularly when Phase 7 (smartphone integration) is introduced. Any changes will be reflected on this page with an updated date and announced via the GitHub repository.
