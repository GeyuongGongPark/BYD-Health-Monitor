개인정보 처리방침

최종 수정일: 2026년 9월 17일

1. 개요

BYD Health Monitor(이하 "앱")는 BYD 차량 내장 디스플레이(DiLink)에서 실행되는 오픈 소스 차량 건강 모니터링 앱입니다.

본 앱은 사용자의 개인 식별 정보를 수집하지 않습니다. 모든 데이터는 차량 기기 내에 저장되며 외부 서버로 전송되지 않습니다.

2. 수집하는 정보

앱이 처리하는 데이터와 저장 위치는 아래와 같습니다.

데이터 항목 내용 저장 위치
차량 고장 코드 BYD HAL API에서 실시간 조회. 23종 고장 코드 활성 여부. 메모리(비저장)
타이어 상태 4개 타이어 압력(kPa), 온도 상태, 공기 누출 감지. 메모리(비저장)
배터리 · 주행거리 배터리 잔량(%), 전기 주행 가능 거리(km), 총 주행거리. 메모리(비저장)
소모품 교체 이력 사용자가 직접 입력한 교체 일자, 교체 시 주행거리, 메모. 기기 내 로컬 DB

차량 데이터는 앱 실행 중 실시간으로 조회되며, 세션이 종료되면 메모리에서 삭제됩니다. 소모품 교체 이력만 사용자 요청에 의해 기기 내 Room 데이터베이스에 저장됩니다.

3. 수집하지 않는 정보

  • 이름, 이메일 주소, 전화번호 등 개인 식별 정보
  • 위치 정보 (GPS, 네트워크 위치)
  • 사용 로그, 이벤트 분석 데이터 (Analytics)
  • 광고 식별자 (ADID, IDFA 등)
  • 카메라, 마이크 데이터
  • 연락처, 캘린더, 사진 등 기기 개인 데이터

4. 데이터 저장 및 보안

소모품 교체 이력은 차량 디스플레이(DiLink) 기기 내 SQLite 데이터베이스(Room)에만 저장됩니다. 외부 서버, 클라우드 스토리지로 전송되거나 동기화되지 않습니다.

  • 앱 삭제 시 기기 내 저장 데이터가 함께 삭제됩니다.
  • 타사 SDK, 광고 네트워크, 분석 도구가 포함되어 있지 않습니다.
  • 인터넷 연결이 없어도 앱의 모든 기능이 동작합니다.

5. 앱 권한

권한 사용 목적
POST_NOTIFICATIONS CRITICAL 긴급 고장 코드 감지 시 상태바 알림 표시. 알림을 원하지 않으면 시스템 설정에서 비활성화할 수 있습니다.
INTERNET Phase 7(스마트폰 연동) 구현 시 사용 예정. 현재 버전에서는 사용하지 않습니다.
FOREGROUND_SERVICE 백그라운드 차량 데이터 모니터링을 위한 포그라운드 서비스 (구현 예정).

6. 제3자 공유

본 앱은 수집된 어떠한 데이터도 제3자에게 판매, 공유, 전송하지 않습니다.

타사 라이브러리는 아래와 같이 사용됩니다. 해당 라이브러리들은 사용자 데이터를 수집하거나 전송하지 않습니다.

  • Jetpack Compose, Hilt, Room — Google Android Jetpack (Apache 2.0)
  • Kotlin Coroutines — JetBrains (Apache 2.0)

7. 어린이 개인정보 보호

본 앱은 차량 운전자를 대상으로 합니다. 13세 미만 어린이를 대상으로 데이터를 수집하지 않습니다.

8. 방침 변경

본 개인정보 처리방침은 앱 업데이트 또는 기능 추가(특히 Phase 7 스마트폰 연동 기능)에 따라 변경될 수 있습니다. 변경 시 이 페이지에 수정일을 표기하고 GitHub 저장소를 통해 공지합니다.
