1. 개요

BYD Health Monitor는 두 가지 앱으로 구성됩니다.

  • 차량용 앱 — BYD 차량 내장 디스플레이(DiLink)에서 실행. 고장 코드, 타이어 상태, 소모품 이력을 관리하고 CRITICAL 고장 발생 시 중계 서버를 통해 컴패니언 앱에 알림을 전송합니다.
  • 컴패니언 앱 — 운전자 스마트폰(iOS / Android)에 설치. CRITICAL 고장 푸시 알림 수신 및 알림 이력을 조회합니다.

본 앱은 사용자의 이름, 이메일, 전화번호 등 개인 식별 정보를 수집하지 않습니다. 서버에 전송되는 데이터는 차량 고장 정보와 푸시 토큰에 한정됩니다.

2. 수집하는 정보

앱이 처리하는 데이터와 저장 위치는 아래와 같습니다.

데이터 항목 내용 저장 위치
차량 고장 코드 BYD HAL API에서 실시간 조회. 23종 고장 코드 활성 여부 및 심각도(CRITICAL/WARNING/INFO). 메모리(비저장)
타이어 상태 4개 타이어 압력(kPa), 온도 상태, 공기 누출 감지. 메모리(비저장)
배터리 · 주행거리 배터리 잔량(%), 전기 주행 가능 거리(km), 총 주행거리. 메모리(비저장)
소모품 교체 이력 사용자가 직접 입력한 교체 일자, 교체 시 주행거리, 메모. 차량 기기 내 로컬 DB
CRITICAL 알림 이력 긴급 고장 감지 시 서버로 전송되는 고장 코드 번호, 심각도, 고장명, 설명, VIN(선택). 알림 이력은 서버 DB에 보관됩니다. 중계 서버 DB
푸시 토큰 (FCM / APNs) 컴패니언 앱 설치 후 페어링 시 생성되는 기기 식별 토큰. 알림 전송에만 사용됩니다. 중계 서버 DB
페어링 코드 / vehicle_id 차량 앱과 컴패니언 앱을 연결하기 위한 임시 6자리 코드(5분 유효). 사용 후 폐기됩니다. vehicle_id는 내부 식별용 UUID입니다. 차량 기기(임시)

차량 실시간 데이터는 세션 종료 시 메모리에서 삭제됩니다. 소모품 이력은 차량 기기 내에만 저장됩니다. 알림 이력과 푸시 토큰은 운전자 알림 전송 목적으로만 중계 서버에 저장됩니다.

3. 수집하지 않는 정보

  • 이름, 이메일 주소, 전화번호 등 개인 식별 정보
  • 위치 정보 (GPS, 네트워크 위치)
  • 사용 로그, 이벤트 분석 데이터 (Analytics)
  • 광고 식별자 (ADID, IDFA 등)
  • 카메라, 마이크 데이터
  • 연락처, 캘린더, 사진 등 기기 개인 데이터

4. 데이터 저장 및 보안

차량 기기(DiLink): 소모품 교체 이력은 기기 내 SQLite(Room)에만 저장됩니다. 앱 삭제 시 함께 삭제됩니다.

중계 서버(Railway.app): CRITICAL 알림 이력과 FCM/APNs 토큰은 Railway에 배포된 PostgreSQL 데이터베이스에 저장됩니다. 토큰은 마지막 활동 후 90일이 경과하면 자동 삭제됩니다. 서버와의 모든 통신은 HTTPS(TLS)로 암호화됩니다.

  • 광고 네트워크, 사용자 행동 분석 도구는 포함되어 있지 않습니다.
  • 수집된 데이터는 알림 전송 및 이력 제공 이외의 목적으로 사용되지 않습니다.

5. 앱 권한

권한 (앱) 사용 목적
POST_NOTIFICATIONS (차량·컴패니언) CRITICAL 긴급 고장 감지 시 알림 표시. 시스템 설정에서 비활성화할 수 있습니다.
INTERNET (차량·컴패니언) 차량 앱: CRITICAL 고장 정보를 중계 서버로 전송. 컴패니언 앱: 알림 이력 조회 및 토큰 등록.
ACCESS_NETWORK_STATE (차량) 네트워크 연결 여부 확인 후 알림 전송 여부 결정.

6. 제3자 서비스

알림 전송을 위해 아래 제3자 서비스를 사용합니다.

  • Firebase Cloud Messaging (Google) — Android 컴패니언 앱 푸시 알림 전송. Firebase 개인정보처리방침
  • Apple Push Notification service (Apple) — iOS 컴패니언 앱 푸시 알림 전송. Apple 개인정보처리방침
  • Railway.app — 중계 서버 및 PostgreSQL 호스팅. Railway 개인정보처리방침

위 서비스는 알림 전송 목적 외에 사용자 데이터를 수집하거나 광고에 활용하지 않습니다.

오픈 소스 라이브러리: Jetpack Compose, Hilt, Room, OkHttp (Apache 2.0) / Flutter, Riverpod, Firebase Flutter SDK (BSD-3)

7. 어린이 개인정보 보호

본 앱은 차량 운전자를 대상으로 합니다. 13세 미만 어린이를 대상으로 데이터를 수집하지 않습니다.
